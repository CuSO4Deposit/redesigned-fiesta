Hardware and software I use, sorted by how far I'd vouch for them. Tier 1 is what I'd pick again and can say why; Tier 2 is what I'm using now but haven't compared enough to recommend.

# Tier 1 / recommended

## Hardware

- Laptop: Toshiba Dynabook G83/M with 8 GB RAM and 256 GB SSD

  - Because it's the lightest laptop I could find. I usually only need an ssh terminal when using a laptop, so I can still accept its lower performance for now.

- Tablet: iPad Pro, 11-inch (3rd generation)

  - The iPad Pro is a music game's best friend: low latency and 120 fps.

- EBook: MiReader

  - A cheap and good option; it works by importing epub files.

## Software (on GNU/Linux)

- Backup: restic

  - Paired with a WebDAV, all my offsite backups rely on restic

- Browser: Firefox

- Compositor: Hyprland

- Database: SQLite, MariaDB

- Game: Terraria

- Newsletter: RSSHub + Miniflux

  - The former converts content into RSS, the latter is an RSS aggregator.

- OS: NixOS

- Password Manager: KeePass

- Search Engine: Duckduckgo Lite

  - Because it returns pure HTML, it's fast enough, and the page is clean.

- Terminal: Ghostty

  - Because it needs very little configuration. I only have 4 lines of config in total.

- Text Editor: Nixvim

  - Because its configuration can be integrated into my system.

- Text Management: Logseq + Git

- Shell: zshell + oh-my-zsh

## Software (on Android / iOS)

- Band: Gadgetbridge

- EBook: Librera FD

- File Sharing: LocalSend

- Game: Arcaea

- Mono font: UbuntuMono Nerd Font Mono

- Note: QuillPad

- Theme: TokyoNight Night
