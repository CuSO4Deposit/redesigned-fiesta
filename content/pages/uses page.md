Hardware and software I use, sorted by how far I'd vouch for them. Tier 1 is what I'd pick again and can say why; Tier 2 is what I'm using now but haven't compared enough to recommend.


# Tier 1 / recommended

## Hardware

  + Laptop: Toshiba Dynabook G83/M with 8 GB RAM and 256 GB SSD


    + 因为这是我能找到的最轻的笔记本电脑。通常使用笔记本电脑时我只需要一个 ssh 终端，因此我目前仍可接受它较低的性能。


  + Tablet: iPad Pro, 11-inch (3rd generation)

    + iPad Pro 是音乐游戏最好的朋友：低延迟和 120 fps。


  + EBook: MiReader

    + 便宜且好用的选择，通过导入 epub 来工作。


## Software (on GNU/Linux)

  + Backup: restic


    + 配合一个 webdav，我的所有异地备份都依赖 restic


  + Browser: Firefox

  + Compositor: Hyprland

  + Database: SQLite, MariaDB

  + Game: Terraria

  + Newsletter: RSSHub + Miniflux

    + 前者用来将内容转换为 RSS，后者是 RSS 聚合器。


  + OS: NixOS

  + Password Manager: KeePass

  + Search Engine: Duckduckgo Lite

    + 因为它是纯 html 返回，速度够快，页面简洁。


  + Terminal: Ghostty

    + 因为不怎么需要配置。我总共只有 4 行配置。


  + Text Editor: Nixvim

    + 因为它的配置可以集成在我的系统里。


  + Text Management: Logseq + Git

  + Shell: zshell + oh-my-zsh

## Software (on Android / iOS)

  + Band: Gadgetbridge


  + EBook: Librera FD

  + File Sharing: LocalSend

  + Game: Arcaea

  + Mono font: UbuntuMono Nerd Font Mono

  + Note: QuillPad

  + Theme: TokyoNight Night
